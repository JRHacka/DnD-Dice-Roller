# Tavern Table (DnD Dice Roller)

A dice tray and party/initiative tracker for 5e-style games. There is no build step. Three.js and fonts load from a CDN. State is saved to `localStorage`. The README describes the user-facing features.

## Code layout
- `index.html`: markup, the import map for Three.js, and the list of scripts.
- `css/style.css`: layout and components. `css/tavern.css`: the palette and the see-through wood panels (wood on a `::before` layer at 84% opacity, plus `backdrop-filter: blur`); it loads second, so it wins. `css/scenes.css`: the full-page fixed scene (`.scene-bg`), `main`'s top margin so the panels start at the characters' feet, and the scene menu. `css/scenekit.css`: the scene kit's frame, parallax, light flicker, particles and overlays.
- `js/` scripts, loaded in this order: `noise.js` (seeded random, tiling noise) → `app.js` (constants, helpers like `$` and `esc`, `state`/`save`, party & initiative, roll log) → `tray.js` (dice pool, `doRoll`, Roll button) → `skins.js` (catalog, `paintSkin`, menu) → `figures.js` (low-poly SVG cast and props: `PARTY`, `FOLK`, `PROP`, `ITEMS`, `HEAD`, `person()`) → `scenekit.js` (the scene kit; also owns the frame constants `VIEW_W`, `VIEW_H`, `TOP`, `BOTTOM`) → `scenes.js` (`SCENES` catalog, one art function per scene, `sceneSvg` with sky above and `planksBelow`/`rocksBelow`/`cobblesBelow`/`tilesBelow` ground below, `applyScene`, menu) → `dice3d.js` (3D table). A small inline startup script at the end of `index.html` calls `syncTray(); renderParty(); renderLog();`.
- **Must keep working when `index.html` is opened straight from the folder (file://).** So the JS files are plain `<script src>` files, not ES modules (browsers block local module files on file://). They share top-level names, so load order matters. `dice3d.js` is an async IIFE that loads Three.js with `await import("three")`; the import map in `index.html` resolves it to the CDN.
- The tray and skins talk to the 3D code through events: `tray:change`, `die:roll`, `skin:change` (plus `window.tavernDice` and `window.tavernSkin` for the state before `dice3d.js` finishes loading).

Reduced motion turns off parallax, flicker and particles. `applyScene` and the menu accept either an SVG string (the old scenes) or a kit build. Verified with a test-only demo scene: layers shift 0/3/8/14/24px by depth, lights blend, no errors, and the old scenes are unchanged. Gotcha: only put texture over drawn shapes (`k.tex()` repeats a shape as texture). A `texRect` over a layer's empty space shows as a gray film over everything behind it. Gotcha: SVG filters default to linear color, which made the grain average 185/255 and wash things out; `color-interpolation-filters="sRGB"` centers it at ~125.
